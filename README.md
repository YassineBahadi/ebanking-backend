## 🔐 Security & Authentication

### Authentication Flow

```
  👤 User                  🅰️ Angular                 🌱 Spring Boot
    │                          │                            │
    │──── Enter Credentials ──►│                            │
    │                          │──── POST /api/auth/login ─►│
    │                          │                            │──► Validate Credentials
    │                          │                            │──► Generate Session/Token
    │                          │◄─── 200 OK + Token ────────│
    │                          │                            │
    │◄─── Access Granted ──────│                            │
    │                          │                            │
    │──── Access Protected ───►│                            │
    │     Resource              │──── GET /api/users ───────►│
    │                          │     + Authorization Header  │──► Validate Token
    │                          │                            │──► Check Role
    │◄─── Protected Data ──────│◄─── 200 OK + Data ─────────│
```

<br/>

### Role-Based Access Control (RBAC)

| Role | Permissions |
|---|---|
| 👑 `ADMIN` | Full access — create, read, update, delete all resources |
| 👤 `USER` | Limited access — read own data, update own profile |

<br/>

### Security Implementation

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            .csrf(csrf -> csrf.disable())
            .sessionManagement(session -> session
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
            );
        return http.build();
    }
}
```

## 🗄️ Database

The application uses a **relational database** managed via **Spring Data JPA** and **Hibernate**.

### Supported Databases

| Database | Use Case | Profile |
|---|---|---|
| 🐬 MySQL 8.x | Production | `prod` |
| 🐘 PostgreSQL | Production alternative | `prod` |
| 💧 H2 In-Memory | Development / Testing | `dev` |

<br/>

### Configuration

```properties
# application.properties

# ── Datasource ──────────────────────────────
spring.datasource.url=jdbc:mysql://localhost:3306/project_db
spring.datasource.username=root
spring.datasource.password=your_password
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# ── JPA / Hibernate ─────────────────────────
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
spring.jpa.database-platform=org.hibernate.dialect.MySQL8Dialect

# ── Server ──────────────────────────────────
server.port=8080
```

## 🚀 Getting Started

### ✅ Prerequisites

Make sure you have the following installed:

```bash
java --version      # Java 21+
mvn --version       # Maven 3.9+
node --version      # Node.js 18+
npm --version       # npm 9+
ng version          # Angular CLI 17+
mysql --version     # MySQL 8+ (or PostgreSQL)
```

<br/>

### 🔧 Backend Setup

**1. Clone the repository**
```bash
git clone https://github.com/yourusername/your-repo-name.git
cd your-repo-name/backend
```

**2. Configure the database**
```bash
# Create your MySQL database
mysql -u root -p
CREATE DATABASE project_db;
```

**3. Update `application.properties`**
```properties
spring.datasource.url=jdbc:mysql://localhost:3306/project_db
spring.datasource.username=YOUR_USERNAME
spring.datasource.password=YOUR_PASSWORD
```

**4. Build and run**
```bash
mvn clean install
mvn spring-boot:run
```

✅ Backend is running at: **`http://localhost:8080`**

<br/>

### 🎨 Frontend Setup

**1. Navigate to frontend directory**
```bash
cd ../frontend
```

**2. Install dependencies**
```bash
npm install
```

**3. Configure the API URL** *(in `environment.ts`)*
```typescript
export const environment = {
  production: false,
  apiUrl: 'http://localhost:8080/api'
};
```

**4. Start the Angular application**
```bash
ng serve
```

✅ Frontend is running at: **`http://localhost:4200`**

## 📡 API Reference

### 🔐 Authentication

| Method | Endpoint | Description | Access |
|---|---|---|---|
| `POST` | `/api/auth/login` | Authenticate user | Public |
| `POST` | `/api/auth/register` | Register new user | Public |
| `POST` | `/api/auth/logout` | Logout current user | Authenticated |

<br/>

### 👥 User Management

| Method | Endpoint | Description | Role Required |
|---|---|---|---|
| `GET` | `/api/users` | Retrieve all users | `ADMIN` |
| `GET` | `/api/users/{id}` | Retrieve user by ID | `ADMIN`, `USER` |
| `POST` | `/api/users` | Create new user | `ADMIN` |
| `PUT` | `/api/users/{id}` | Update user by ID | `ADMIN` |
| `DELETE` | `/api/users/{id}` | Delete user by ID | `ADMIN` |

<br/>

### 📦 Example Request & Response

**POST** `/api/users`

```json
// Request Body
{
  "firstName": "Yassine",
  "lastName": "Bahadi",
  "email": "yassine@example.com",
  "role": "USER",
  "password": "securePassword123"
}

// Response — 201 Created
{
  "id": 1,
  "firstName": "Yassine",
  "lastName": "Bahadi",
  "email": "yassine@example.com",
  "role": "USER",
  "createdAt": "2025-01-01T12:00:00Z"
}
```
